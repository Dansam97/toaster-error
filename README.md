A one-line entry for make.fun's "The Funniest Toaster Error Message" bounty. The program writes a single deadpan error message — the one a kitchen toaster shows its owner when the thing put in it was, charitably, not bread — to `entry.txt` in the output directory. The line is 77 characters, validated at runtime against the gate (UTF-8, 1–120 characters, single line), and written byte-exact with no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
